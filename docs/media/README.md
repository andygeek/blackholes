# README media

The previews show the app in its dark theme with a sample project:

- `blackholes-demo.gif`: a project with three repositories, then two of its
  tasks opening with their own branches, context and links.
- `project-repositories.gif`: the same recording, focused on the project tree.
- `task-sessions.webp`: screenshot of the Agents list with a session that needs
  attention, and a task with its agent session and one worktree per repository.
- `source-control.webp`: screenshot of source control with a task's staged
  changes and the diff of one file.

The GIFs are excerpts of the public website
[recording](https://blackholes.dev/videos/blackholes-repositories.mp4), which the
README links to for full resolution. Refresh these previews when the interface
changes. Do not add recordings containing credentials, private conversations,
or customer data.

## Agent badges

`codex-badge.svg`, `claude-code-badge.svg` and `antigravity-badge.svg` use the
same provider symbols as `assets/icons/`, inside compact labels for the README.
They identify supported third-party CLIs and do not imply endorsement.
