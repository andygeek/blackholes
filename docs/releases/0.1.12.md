# Blackholes 0.1.12

Review agent work with Git history, make small manual commits, and search across your repository.

## Changes

- Added manual commits with a message field, per-file and group staging actions,
  and separate staged/pending diffs. Existing Git identity, hooks, and signing
  settings apply.
- Added repository text search with grouped results, line navigation, case and
  whole-word options, regular expressions, and include/exclude file filters.
- Collapsed Graph stays at the bottom of Source Control. The file filter has
  been removed from Changes.
- Added a collapsible Source Control graph with commit ancestry, branch and tag
  labels, outgoing commits, and incoming/outgoing counts. Open commits to inspect
  their files and historical diffs, including selectable parents for merges.
- Added explicit fetch and a push preview showing the destination branch and
  commit. Push uses existing Git authentication and never forces an update.
- Git metadata changes refresh the graph while Source Control is open, including
  changes made by agents in linked worktrees.
- Removed the Accounts and Usage pages, the global provider selector, and the
  built-in account authentication flow from Settings. Sign in through each
  provider's CLI; the bottom bar still shows local Claude and Codex usage.
- New terminals use the computer's CLI account configuration. Saved sessions
  retain their existing profiles, including legacy isolated Blackholes profiles.
  Existing account files are preserved.
- MCP settings now show one row per client. Expand Configuration details to
  inspect profile locations, individual statuses, and warnings. Automatic MCP
  setup and the refresh connection action remain available.
- Removed the Manage account shortcut from MCP settings and the hover tooltip
  over the memory and terminal indicators. The indicators remain visible.
- Updated the usage, architecture, and MCP documentation.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.12-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and close active sessions before installing an update.

The release includes the DMG installer, a Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums. Provider CLIs are installed and
authenticated separately; they are not bundled with Blackholes.

## Validation and limitations

- Release compilation uses `./scripts/build-release` for the embedded frontend
  and Rust binaries. Distribution artifacts are signed and notarized before
  publication, with signature, ticket, and checksum verification.
- Automated tests, application launches, manual installation, and an update
  from an older installation were not performed for this release.
- Account usage depends on the installed CLI and its signed-in local account.
  The bottom bar does not query legacy isolated Blackholes profiles.
- Memory reports only the Blackholes process, excluding agent, shell, and
  WebKit subprocesses. Terminal count includes open terminal panes.
