# Blackholes 0.1.16

Los grupos de worktrees reúnen tus ramas, agentes y contexto actual, con una página más simple que puedes editar directamente.

## Cambios

- **Las tareas ahora son grupos de worktrees.** Un grupo reúne los worktrees y
  ramas de varios repositorios. Se conservan los grupos, identificadores,
  archivos y sesiones existentes, incluidas las llamadas MCP con nombres anteriores.
- **Edición directa con autoguardado.** Escribe en el título y el contexto, elige
  un emoji o icono de la app y agrega varios pull requests de GitHub o enlaces
  de contexto. Los enlaces solo necesitan tipo y URL. Puedes seguir escribiendo
  durante un guardado; los cambios de otro agente conservan tu borrador para revisarlo.
- **Contexto siempre vigente.** Las instrucciones generadas para Claude/Codex y
  el MCP piden reemplazar lo obsoleto y mantener los enlaces relevantes,
  conservando requisitos y pendientes en lugar de acumular un historial de avances.
- **Agents muestra terminales activas.** Las sesiones restaurables permanecen
  en Proyectos hasta activarlas. Agents incluye sesiones en reposo, trabajando o
  esperando atención con procesos vivos; las inactivas conservan su orden guardado.
- **Cierre de grupos para liberar disco.** Una sola confirmación muestra las
  terminales, cambios y archivos extra antes de eliminar los worktrees gestionados
  y la carpeta del grupo. Las ramas Git se conservan por defecto. Las pestañas
  restauradas sin proceso ya no bloquean el cierre; el resultado conserva los
  identificadores de sesión de Claude/Codex.
- **Cierre en lote por MCP.** Cierra hasta 32 grupos con políticas explícitas para
  terminales, cambios sin guardar en Git y archivos extra. Un grupo bloqueado no
  detiene el lote. Se protege el grupo que origina la llamada cuando se identifica
  por terminal, carpeta o procesos; algunos clientes externos no exponen esos datos.
- **Integración de agentes más fiable.** Los comandos se pasan al shell de inicio
  con la conexión MCP actual, evitando escribir configuraciones largas en el PTY.
  Los hooks de seguimiento son asíncronos. Se admiten los reportes nativos de
  estado de Claude y el transporte actual del app-server de Codex.
- **Resultados MCP como objetos.** Los listados usan objetos con colecciones
  identificadas, corrigiendo clientes que rechazaban arrays en structured content.
  Las herramientas nuevas de grupos conviven con los alias anteriores.

## Instalar o actualizar

Requiere **macOS 13 o posterior con Apple Silicon**. Descarga
`Blackholes-0.1.16-arm64.dmg`, ábrelo y arrastra Blackholes a Aplicaciones.
Las instalaciones firmadas existentes pueden usar **Buscar actualizaciones**.
Guarda tu trabajo y termina las sesiones activas antes de instalar o reiniciar.

Cerrar un grupo puede eliminar permanentemente sus worktrees y archivos extra:
revisa la confirmación o las políticas de descarte del MCP. Consulta los resultados
si hay bloqueos o una limpieza parcial. Reconecta los clientes MCP después de
actualizar para refrescar las herramientas; revisa los hooks nuevos de Codex en
`/hooks` si tu CLI lo requiere.

La publicación incluye el instalador DMG, el ZIP y el appcast de Sparkle,
el código fuente correspondiente y las sumas SHA-256.

## Validación y limitaciones

- Compilada con `./scripts/build-release`, incluidos el frontend integrado y los
  binarios de Rust. La distribución se firma y notariza; se verifican las firmas,
  tickets incorporados y sumas finales antes de publicar.
- Durante la preparación no se ejecutaron nuevas pruebas automatizadas, no se
  abrió la app ni se realizó una instalación manual o actualización desde una
  versión anterior. Compilar y notarizar no demuestra el comportamiento en ejecución.
- El editor guarda texto plano o Markdown. El mantenimiento del contexto depende
  de las instrucciones a los agentes; no hay un modelo que lo reescriba por su cuenta.
