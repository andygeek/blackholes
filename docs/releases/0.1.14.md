# Blackholes 0.1.14

Keep account usage up to date and discover what changed after every update.

## Automatic account usage

- Codex and Claude usage refreshes when Blackholes opens, every **10 minutes**
  while it is running, and when you click the refresh button.
- The bottom bar only shows providers installed on your computer. Each provider
  is detected independently, including installations available through your shell.
- Temporary connection, account, or provider failures keep the last available
  report. Usage queries run in the background with time limits and never open
  blocking error dialogs. An asterisk identifies a report whose refresh failed.
- Providers installed or removed while the app is open are detected at the next
  automatic or manual refresh.

## Release notes inside Blackholes

- The current version's release notes appear on the main screen the first time
  you open a new version, in your selected language.
- Close them with the **X** in the upper-right corner to return to your workspace.
  Blackholes remembers the dismissal for that version.
- Use the small rocket icon beside the version to read the notes again.
- Notes are included in the application and remain available offline.

## Agent model selection through MCP

- Select a model when creating a task with `agentModel`, or when launching task
  agents with `model`. Batch launches can use one model or a different one per task.
- Codex, Claude, Gemini, and OpenCode receive the requested model, and restored
  terminals retain that selection. Omitting the model uses the provider's default.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.14-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and close active sessions before installing an update.

Provider CLIs are installed and authenticated separately. Usage availability
depends on each provider's account and supported metadata interface; unavailable
reports do not prevent you from using Blackholes.
