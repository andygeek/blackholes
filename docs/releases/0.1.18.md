# Blackholes 0.1.18

See which Claude Code sessions still have work running in the background, add Antigravity to the agents you work with, edit a project right on its page, and use voice input in agents inside Blackholes terminals.

## Changes

- **Background work in blue.** A Claude Code session that finishes responding while something keeps running, such as a shell command, a subagent or a workflow, gets a blue row in Agents and blue gears turning over its icon. The response is announced as usual; blue only says that work continues behind it. Hover the session to see how many tasks are running.
- **Blue throughout the project tree.** The session shows the same gears in the project tree, and project and task icons show a blue dot when one of their sessions has background work and nothing else is pending. Green and yellow notices and the working spinner take priority on the icon.
- **Antigravity and the agents you use.** **Settings → Agents** lists Claude Code, Codex and Antigravity (`agy`). Each agent you select appears in the `+` menus and shows its plan usage in the bottom bar; the ones you leave out are neither shown nor queried. Antigravity reports a limit per group of models, so the bar shows the group closest to its cap and its panel lists them all.
- **Projects edited on their page.** **Edit project** opens the project page with its name focused instead of a dialog. Type the name, pick a color, and click the large icon to choose an emoji or a bundled icon, as in a task. Each change is saved at once.
- **Worktree Groups are now tasks.** The interface calls them tasks: **Add task**, **Edit task**, **Close task**. They work the same, and the MCP tools keep their names.
- **Notifications with the reply.** A completion notification now shows the beginning of the agent's reply as plain text, and its title names the project and the session or task it came from.
- **Voice input in terminal agents.** Blackholes now requests microphone access from macOS, so voice input in Claude Code and Codex can hear you. macOS asks once, the first time an agent records.
- **Project colors that read in the light theme.** Every project and task color has its own tone for light backgrounds, names with the default color use the regular text color, and the working spinner is drawn dark on the light sidebar.
- **Easier text selection.** Selected text in native fields uses a color that stays legible in light and dark themes, and a triple click selects the whole content of a single-line field.
- **Smaller fixes.** The form for creating a project takes keyboard focus when it opens, and the Codex hook returns a valid response to older Codex versions.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.18-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and finish active sessions before installing or relaunching.

The release includes the DMG installer, Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums.

## Validation and limitations

- Built with `./scripts/build-release`, including the embedded frontend and Rust binaries. Distribution signatures, Apple notarization, stapled tickets, and final checksums are verified before publication.
- Rust unit tests were run during release preparation. No end-to-end updater run was performed. Compilation and notarization do not establish runtime or updater behavior.
- Background work is reported by Claude Code and refreshed each time it finishes responding, so a task you stop yourself stays marked until the next response. Codex hooks do not report background work; Codex sessions are never marked.
- Antigravity is off by default: turn it on in **Settings → Agents**. Its usage is read from the `agy` CLI signed in on this computer, without starting an agent turn.
- Voice input needs microphone permission for Blackholes. If you denied it, enable it in **System Settings → Privacy & Security → Microphone**.
