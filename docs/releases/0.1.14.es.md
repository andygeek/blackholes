# Blackholes 0.1.14

Mantén actualizado el uso de tus cuentas y descubre qué cambió después de cada actualización.

## Uso de cuentas actualizado automáticamente

- El uso de Codex y Claude se consulta al abrir Blackholes, cada **10 minutos**
  mientras la app está abierta y al pulsar el botón de actualizar.
- La barra inferior solo muestra los proveedores instalados en tu computadora.
  Cada proveedor se detecta por separado, incluidas las instalaciones disponibles
  a través de tu shell.
- Si falla temporalmente la conexión, la cuenta o el proveedor, se conserva el
  último reporte disponible. Las consultas se ejecutan en segundo plano, tienen
  un tiempo límite y no abren diálogos de error que bloqueen la app. Un asterisco
  identifica un reporte cuya actualización falló.
- Los proveedores que instales o desinstales con la app abierta se detectan en
  la siguiente actualización automática o manual.

## Novedades dentro de Blackholes

- Las novedades de la versión aparecen en la pantalla principal la primera vez
  que abres una versión nueva, en el idioma que hayas elegido.
- Ciérralas con la **X** de la esquina superior derecha para volver a tu espacio
  de trabajo. Blackholes recuerda que las cerraste para esa versión.
- Usa el pequeño icono de cohete junto a la versión para volver a leerlas.
- Las notas vienen incluidas en la aplicación y están disponibles sin conexión.

## Selección de modelos mediante MCP

- Elige un modelo al crear una tarea con `agentModel` o al iniciar sus agentes
  con `model`. Puedes usar un modelo para todo el lote o uno distinto por tarea.
- Codex, Claude, Gemini y OpenCode reciben el modelo solicitado, y las terminales
  restauradas conservan la selección. Si lo omites, se usa el modelo predeterminado
  del proveedor.

## Instalar o actualizar

Requiere **macOS 13 o posterior con Apple Silicon**. Descarga
`Blackholes-0.1.14-arm64.dmg`, ábrelo y arrastra Blackholes a Aplicaciones.
Las instalaciones firmadas existentes pueden usar **Buscar actualizaciones**.
Guarda tu trabajo y cierra las sesiones activas antes de instalar una actualización.

Los CLI de los proveedores se instalan y autentican por separado. La disponibilidad
del uso depende de la cuenta y de la interfaz de metadatos de cada proveedor;
un reporte no disponible no impide usar Blackholes.
