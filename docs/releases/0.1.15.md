# Blackholes 0.1.15

A small visual fix that keeps your workspace within reach while you catch up on recent releases.

## Changes

- Release notes now stay inside the **central workspace**, with the sidebar
  visible and resizable. Select a project, task, repository, or terminal to open it directly.
- A compact history shows the **latest three versions**. The current version's
  changes are expanded, and previous versions can be opened individually.
- A link to **all releases on GitHub** opens the complete history in your browser.
  Recent notes remain available offline in English and Spanish.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.15-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and close active sessions before installing an update.

The release includes the DMG installer, a Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums.

## Validation and limitations

- Built with `./scripts/build-release`, including the embedded frontend and
  Rust binaries. Distribution artifacts are signed and notarized, with signature,
  ticket, and checksum verification before publication.
- Automated tests, application launches, manual installation, and an update
  from an older installation were not performed. The visual changes have not
  been independently verified at runtime.
