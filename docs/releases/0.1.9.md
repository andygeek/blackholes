# Blackholes 0.1.9

Blackholes brings terminal agent sessions, task context, and repositories
together in one workspace.

## Changes

- Removed the built-in bot conversations and internal chat engine. Continue
  using installed coding-agent CLIs in native terminals, with provider accounts,
  session restoration, and MCP task launches.
- Click a task title to edit its objective, acceptance criteria, pull request
  link, and external task link. Agents can read and update these fields through
  MCP. Unsaved drafts survive navigation within the current app session;
  concurrent changes preserve the draft for reconciliation.
- Project titles open an overview of tasks, repositories, and sessions. Existing
  task notes are available read-only under **Previous notes**; previous project
  and task note files remain on disk.
- Task and repository `+` menus offer **Blank Terminal**, **Claude**, and
  **Codex**. Task `…` menus contain **Edit task** and **Delete task**.
- The project-tree collapse button now uses a double up-chevron.
- Quick Open (`Cmd+O`) supports `Cmd+A`, `Cmd+C`, `Cmd+X`, and `Cmd+V`
  through the native clipboard.
- Creating a project without selecting repositories now creates and registers
  a Git repository inside its container, including an initial commit for task
  worktrees. Existing empty projects are not modified automatically.
- Updated the README, task and MCP documentation, and public release guide.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.9-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use the in-app updater. Save pending work
and close active sessions before installing an update.

The release includes the DMG installer, a Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums. Provider CLIs are installed and
authenticated separately; they are not bundled with Blackholes.

## Validation and limitations

- Release compilation uses `./scripts/build-release` for the embedded frontend
  and Rust binaries. Distribution artifacts are signed and notarized before
  publication, with signature, ticket, and checksum verification.
- Automated tests, application launches, manual installation, and an update
  from an older installation were not performed for this release.
- Native notification behavior is unchanged. Notices depend on macOS
  notification permission and presentation settings.
- Website recordings show an earlier interface.
