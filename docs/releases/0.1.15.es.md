# Blackholes 0.1.15

Una pequeña corrección visual para mantener tu espacio de trabajo a mano mientras revisas las últimas novedades.

## Cambios

- Las novedades ahora ocupan solo el **panel central**, con el menú lateral
  visible y ajustable. Elige un proyecto, tarea, repositorio o terminal para abrirlo directamente.
- Un historial compacto muestra las **últimas tres versiones**. Los cambios de
  la versión actual aparecen abiertos y puedes desplegar las versiones anteriores por separado.
- Un enlace a **todas las versiones en GitHub** abre el historial completo en
  tu navegador. Las notas recientes siguen disponibles sin conexión en español e inglés.

## Instalar o actualizar

Requiere **macOS 13 o posterior con Apple Silicon**. Descarga
`Blackholes-0.1.15-arm64.dmg`, ábrelo y arrastra Blackholes a Aplicaciones.
Las instalaciones firmadas existentes pueden usar **Buscar actualizaciones**.
Guarda tu trabajo y cierra las sesiones activas antes de instalar una actualización.

La publicación incluye el instalador DMG, el ZIP y el appcast de Sparkle,
el código fuente correspondiente y las sumas SHA-256.

## Validación y limitaciones

- Compilada con `./scripts/build-release`, incluidos el frontend integrado y
  los binarios de Rust. Los archivos de distribución se firman y notarizan,
  verificando sus firmas, tickets y sumas antes de publicar.
- No se ejecutaron pruebas automatizadas, no se abrió la aplicación ni se
  realizó una instalación manual o una actualización desde una versión anterior.
  Los cambios visuales no se verificaron de forma independiente en ejecución.
