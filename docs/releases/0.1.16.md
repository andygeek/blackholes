# Blackholes 0.1.16

Worktree Groups bring your branches, agents and current context together, with a simpler page you can edit directly.

## Changes

- **Tasks are now Worktree Groups.** A group keeps the worktrees and branches of
  several repositories together. Existing groups, IDs, files and sessions remain
  compatible, including older task-named MCP calls.
- **Edit in place with autosave.** Type directly in the title and context, choose
  an emoji or app icon, and add several GitHub pull requests or context links.
  Links need only a type and URL. New edits survive an in-flight save; concurrent
  agent changes preserve your draft for review.
- **Keep context current.** Generated Claude/Codex instructions and MCP guidance
  tell agents to rewrite obsolete context and maintain relevant links, preserving
  requirements and unresolved work instead of appending a progress history.
- **Agents shows active terminals.** Restorable sessions stay in Projects until
  activated. Idle, working and attention sessions with live terminal processes
  appear in Agents; inactive sessions retain their saved order.
- **Close groups and reclaim disk.** One UI confirmation lists terminals, changes
  and extra files before removing managed worktrees and the group folder. Git
  branches are preserved by default. Restored tabs without processes no longer
  block closure, and Claude/Codex session IDs are retained in closure results.
- **Batch closure through MCP.** Close up to 32 groups with explicit terminal,
  uncommitted-change and extra-file policies. A blocked group does not stop the
  batch. The calling group is protected when its terminal, cwd or process ancestry
  can be identified; detached external clients may not expose that information.
- **More reliable agent integration.** Agent launches pass commands through the
  login shell, inject the current MCP connection and avoid typing long settings
  into the PTY. Tracking hooks run asynchronously. Claude native terminal status
  reports and current Codex app-server transport are supported.
- **Object-shaped MCP results.** List tools return named object envelopes, fixing
  clients that rejected array-valued structured content. New Worktree Group tool
  names coexist with callable legacy aliases.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.16-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and finish active sessions before installing or relaunching.

Closing a group can permanently remove its worktrees and extra files: review the
confirmation or MCP discard policies. Read closure results for blocked or partial
cleanup. Reconnect external MCP clients after updating to refresh tool schemas;
review changed Codex tracking hooks through `/hooks` if required by your CLI.

The release includes the DMG installer, Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums.

## Validation and limitations

- Built with `./scripts/build-release`, including the embedded frontend and
  Rust binaries. Distribution artifacts are signed and notarized; signatures,
  stapled tickets and final checksums are verified before publication.
- No new automated test run, application launch, manual installation or update
  from an older installed version was performed during release preparation.
  Compilation and notarization do not establish runtime or updater behavior.
- The document editor stores plain text/Markdown source. Context maintenance is
  guidance for agents, not a background model that rewrites documents itself.
