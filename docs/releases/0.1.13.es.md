# Blackholes 0.1.13

Crea proyectos y tareas con formularios más claros, encuentra repositorios más rápido y abre terminales de proyectos directamente desde clientes MCP.

## Cambios

- Se rediseñó la creación de proyectos con opciones de configuración desplegables
  y pestañas para carpetas locales y GitHub. Selecciona los repositorios locales
  antes de añadirlos o agrega repositorios de GitHub mediante sus URL completas.
  GitHub ahora usa su propio logo.
- Se añadió búsqueda de repositorios al crear tareas, filas compactas, un contador
  de selección y acciones para seleccionar o deseleccionar los resultados de
  búsqueda sin perder las selecciones que quedan fuera del filtro.
- Las opciones de ramas ahora se organizan en crear una rama para la tarea,
  continuar una rama local o usar una rama de origin. Los menús incluyen
  explicaciones y navegación por teclado. El punto de partida opcional aparece
  cerrado y la opción de recrear una rama explica cómo se conserva su respaldo.
- Se unificaron los campos de los modales con bordes de enfoque más sutiles y
  controles más ligeros. Se quitaron separadores innecesarios y el menú lateral
  solo reserva espacio adicional cuando necesita desplazamiento.
- Se actualizó el enfoque del teclado y los eventos de **Cmd+O** y **Cmd+P**
  al abrir las búsquedas desde una terminal, incluidos los atajos del portapapeles
  y las flechas nativas de macOS. Ambos atajos se añadieron al espacio de trabajo vacío.
- Se añadió la herramienta MCP `open_project_terminal` para abrir un shell en un
  proyecto o repositorio sin crear una tarea y ejecutar opcionalmente un comando
  de una sola línea. Las terminales permanecen visibles en Blackholes; los
  comandos no se repiten al restaurar una sesión. Por defecto se conserva la
  vista actual, con una opción para mostrar y enfocar la terminal nueva.
- Se actualizaron la documentación MCP, las instrucciones de integración y
  los avisos de terceros.

## Instalar o actualizar

Requiere **macOS 13 o posterior con Apple Silicon**. Descarga
`Blackholes-0.1.13-arm64.dmg`, ábrelo y arrastra Blackholes a Aplicaciones.
Las instalaciones firmadas existentes pueden usar **Buscar actualizaciones**.
Guarda tu trabajo y cierra las sesiones activas antes de instalar una actualización.

La publicación incluye el instalador DMG, el ZIP y el appcast de Sparkle,
el código fuente correspondiente y las sumas SHA-256. Los CLI de los proveedores
se instalan y autentican por separado; no vienen incluidos en Blackholes.

## Validación y limitaciones

- La compilación de release usa `./scripts/build-release` para el frontend
  integrado y los binarios de Rust. Los archivos de distribución se firman y
  notarizan antes de publicar, verificando firmas, tickets y sumas.
- No se ejecutaron pruebas automatizadas, no se abrió la aplicación ni se
  realizó una instalación manual o una actualización desde una versión anterior.
  Los cambios de interfaz y teclado no se verificaron de forma independiente en ejecución.
- Esta versión solo admite Apple Silicon. El comando de terminal por MCP debe
  ser de una sola línea y de hasta 1.000 bytes; cada llamada abre una terminal nueva.
