# Blackholes 0.1.17

See which agents finished responding, which need your input, and which are still working, with a sidebar you can adjust to your workspace.

## Changes

- **Clear response states.** Green means a response is ready; yellow means the agent needs your response or permission. Notifications sit over a dimmed provider icon, while a white spinner indicates work in progress.
- **Agents ordered by attention and activity.** Pending notifications appear first, newest first, followed by working agents and then idle agents. Manual ordering remains available within working or idle sessions.
- **Notifications survive a restart.** Unacknowledged agent notices remain visible until you open their session. Completion notices no longer disappear when a provider returns to idle or get replaced by startup messages.
- **Status throughout the project tree.** Project and Worktree Group icons summarize pending notices, including agents inside repositories. Yellow takes priority when both kinds exist. Collapsed Agents shows a notification dot beside its title.
- **Adjustable sidebar sections.** Drag the divider between Agents and Projects vertically; the saved proportion returns after reopening. Double-click restores the default split. Group icons also appear beside their agent's context.
- **A more consistent interface.** Aligned tree icons and labels, shared light and dark colors, a matching Settings sidebar width, and solid green New labels make navigation easier to scan. Release notes use a simpler layout without decorative cards.
- **Terminal content stays behind dialogs.** Native macOS transparency is enabled for overlays so confirmations can dim the current terminal without replacing its content with an opaque background. Temporary reveal highlights no longer add a side stripe.
- **Compact progress indicators.** Working spinners remain visible over dimmed logos and animate independently of global CSS transition rules.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.17-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and finish active sessions before installing or relaunching.

The release includes the DMG installer, Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums.

## Validation and limitations

- Built with `./scripts/build-release`, including the embedded frontend and Rust binaries. Distribution signatures, Apple notarization, stapled tickets, and final checksums are verified before publication.
- No automated tests or end-to-end updater run were performed during release preparation. Compilation and notarization do not establish runtime or updater behavior.
- Agent states follow structured provider hooks and terminal status events. A question written only as ordinary response text can still be classified as a completed response.
