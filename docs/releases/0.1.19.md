# Blackholes 0.1.19

Programs running in Blackholes terminals can now follow the app's light or dark theme.

## Changes

- **Terminal programs follow your theme.** Agents and other terminal programs that ask the terminal for its colors now receive the ones of the Blackholes theme, so they can choose colors that read on a light or a dark background.
- **Told when the theme changes.** Programs that support color scheme reports are notified when you switch between light and dark, without restarting them.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.19-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and finish active sessions before installing or relaunching.

The release includes the DMG installer, Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums.

## Validation and limitations

- Built with `./scripts/build-release`, including the embedded frontend and Rust binaries. Distribution signatures, Apple notarization, stapled tickets, and final checksums are verified before publication.
- Rust unit tests were run during release preparation. No end-to-end updater run was performed. Compilation and notarization do not establish runtime or updater behavior.
- Whether a program adapts depends on the program: it has to ask the terminal for its colors or support color scheme reports. Sessions already running keep the colors they chose until the program asks again.
