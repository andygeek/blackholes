# Blackholes 0.1.10

Account usage at a glance and a more compact workspace for terminal agents.

## Changes

- Added a bottom bar for the local Claude Code and Codex accounts. Click a
  provider to see its available usage limits, reset times, and last update.
- The bar prefers the five-hour allowance and falls back to weekly or another
  reported limit. Labels reflect the actual window; missing limits are omitted
  from the details panel, while a valid zero percent remains visible.
- Refresh both providers with the adjacent refresh button. Its arrow stays
  visible and rotates until the requests finish. Failed requests preserve the
  previous report and mark it as outdated.
- Fixed usage panels closing immediately when focus moves into them. Keyboard
  shortcuts and Dock activation continue to target the main workspace.
- Added the open-terminal count and Blackholes process memory usage on the
  right side of the bar.
- Agents and Projects can be collapsed independently by clicking their arrow
  or title. Their state is saved across restarts, and the remaining section
  uses the available space. Section headers and Settings are more compact.
- The home screen now displays the Blackholes logo above its description.
- Removed the blue outline around the active terminal.
- Shortened the README and organized the documentation, with contributor,
  supported-agent, and star-history links. Downloads point to blackholes.dev.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.10-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and close active sessions before installing an update.

The release includes the DMG installer, a Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums. Provider CLIs are installed and
authenticated separately; they are not bundled with Blackholes.

## Validation and limitations

- Release compilation uses `./scripts/build-release` for the embedded frontend
  and Rust binaries. Distribution artifacts are signed and notarized before
  publication, with signature, ticket, and checksum verification.
- Automated tests, application launches, manual installation, and an update
  from an older installation were not performed for this release.
- Account usage is requested at startup and on manual refresh. Availability
  depends on the installed CLI and its signed-in account; the app does not
  infer an unlimited allowance when a limit is missing.
- Memory reports only the Blackholes process, excluding agent, shell, and
  WebKit subprocesses. Terminal count includes open terminal panes.
- Website recordings may show an earlier interface.
