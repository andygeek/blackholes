# Blackholes 0.1.13

Create projects and tasks with clearer forms, find repositories faster, and
open project terminals directly from MCP clients.

## Changes

- Redesigned project creation with expandable setup choices and tabs for local
  folders and GitHub. Select local repositories before adding them, or queue
  GitHub repositories using their full URLs. GitHub now uses its own logo.
- Added repository search to task creation, compact selection rows, a selection
  count, and actions that select or deselect the current search results without
  losing selections outside the filter.
- Reorganized branch options around creating a task branch, continuing a local
  branch, or using a branch from origin. Custom menus include explanations and
  keyboard navigation. The optional starting point is collapsed by default,
  and recreating a branch clearly identifies its backup behavior.
- Unified modal field styling with subtler focus borders and lighter controls.
  Removed unnecessary separators and reserved extra sidebar space only when
  scrolling is needed.
- Updated keyboard focus and event routing for the **Cmd+O** and **Cmd+P** search
  overlays when opened from a terminal, including clipboard shortcuts and
  native macOS arrow-key handling. Added both shortcuts to the empty workspace.
- Added the MCP tool `open_project_terminal` to open a shell in a project or
  repository without creating a task, optionally running a single-line command.
  Terminals remain visible in Blackholes; commands are not replayed when a saved
  session is restored. The default keeps the current view, with an option to
  reveal and focus the new terminal.
- Updated MCP documentation, integration instructions, and third-party notices.

## Install or update

Requires **macOS 13 or later on Apple Silicon**. Download
`Blackholes-0.1.13-arm64.dmg`, open it, and drag Blackholes into Applications.
Existing signed installations can use **Check for updates**. Save pending work
and close active sessions before installing an update.

The release includes the DMG installer, a Sparkle update ZIP and appcast,
corresponding source, and SHA-256 checksums. Provider CLIs are installed and
authenticated separately; they are not bundled with Blackholes.

## Validation and limitations

- Release compilation uses `./scripts/build-release` for the embedded frontend
  and Rust binaries. Distribution artifacts are signed and notarized before
  publication, with signature, ticket, and checksum verification.
- Automated tests, application launches, manual installation, and an update
  from an older installation were not performed for this release. The interface
  and keyboard changes have not been independently verified at runtime.
- This release targets Apple Silicon only. The MCP terminal command must be a
  single line of at most 1,000 bytes; each call opens a new terminal.
